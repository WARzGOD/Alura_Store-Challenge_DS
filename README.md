# Alura_Store-Challenge_DS
🏪 Desafio Data Science - Alura Store
📘 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio de Data Science, com o objetivo de auxiliar o Senhor João, proprietário da rede Alura Store, a decidir qual de suas quatro lojas deve ser vendida para iniciar um novo empreendimento.

A decisão foi baseada em uma análise de dados reais de vendas, avaliações de clientes e custos de frete, identificando a loja com menor eficiência operacional e financeira.

<h3>🎯 Objetivo</h3>

O principal objetivo é identificar qual loja apresenta o pior desempenho geral, considerando métricas como:

💰 Faturamento total

🛒 Categorias de produtos mais e menos vendidas

⭐ Média de avaliações dos clientes

📦 Produtos mais e menos vendidos

🚚 Frete médio por loja

Ao final, foi gerada uma recomendação fundamentada em dados e visualizações, ajudando o cliente a tomar uma decisão estratégica.

<h3>🧠 Etapas da Análise</h3>
1️⃣ Faturamento Total

Cálculo da soma dos preços de venda de cada loja para determinar o desempenho financeiro geral.
📊 Gráfico utilizado: Pizza (distribuição percentual do faturamento entre as lojas)

2️⃣ Vendas por Categoria

Análise da quantidade de produtos vendidos por categoria, destacando os tipos mais populares em cada loja.
📊 Gráfico utilizado: Barras horizontais (categorias mais e menos vendidas)

3️⃣ Avaliação Média dos Clientes

Cálculo da média das avaliações de compra, indicando o nível de satisfação do cliente com cada loja.
📊 Gráficos utilizados: Boxplot, dispersão e barras horizontais (comparação visual das médias e dispersão das notas)

4️⃣ Produtos Mais e Menos Vendidos

Identificação dos produtos que mais e menos contribuíram para as vendas de cada loja.
📊 Gráfico utilizado: Barras invertidas e Pareto (representando a concentração das vendas)

5️⃣ Frete Médio

Cálculo do custo médio de frete por loja, representando o custo logístico percebido pelo cliente.
📊 Gráfico utilizado: Linha (tendência do custo médio de frete por loja)

<h3>🧩 Tecnologias Utilizadas:</h3>

🐍 Python

📦 Pandas — manipulação e limpeza de dados

📊 Matplotlib / Seaborn — visualização dos dados

💻 Jupyter Notebook — análise interativa e visual

📈 Principais Insights

A Loja 1 apresentou o maior faturamento, porém também as piores avaliações de clientes e o frete mais alto.

A Loja 3 se destacou com melhores avaliações e boa satisfação, embora com menor diversificação de produtos.

A Loja 2 mostrou desempenho equilibrado em todas as métricas, sendo a mais estável da rede.

A Loja 4 teve menor faturamento, mas baixo custo de frete, indicando potencial de crescimento.

<h3>🧾 Conclusão</h3>

Com base em todos os dados e análises realizadas, recomenda-se que o Senhor João venda a Loja 1.
Apesar de seu alto faturamento, a Loja 1 demonstra ineficiência operacional, baixo nível de satisfação dos clientes e alto custo logístico — fatores que comprometem sua sustentabilidade no longo prazo.

Vender essa loja agora, enquanto ainda possui bom faturamento, é uma decisão estratégica que permitirá concentrar recursos nas lojas mais promissoras.
